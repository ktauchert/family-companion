## Ziel

Haushalt-UI an Listen-Row-Stil; Check-in-Snapshot in Web-Chrome und oben auf Heute (Mobile); Settings + Impressum/Datenschutz als Shell. **Kein** dynamisches Energie-Budget (Phase 4, ADR 0012).

## Entscheidungen (User-Test 2026-09-15)

| Thema | Entscheidung |
| --- | --- |
| Haushalt Mitglieder | **MemberRow** wie Listen (E-Mail prominent, Rolle als Pill); Entfernen für **Inhaber** sichtbar (`rust`) |
| Mitglieder entfernen | **Bereits implementiert** (Phase 1) — nur UX-Polish; Nicht-Inhaber nur Austreten |
| Einladungen | Link zu Verwaltung bleibt; Inhaber-only unverändert |
| Nav Icons | Siehe 2.1 #12 — hier nicht doppeln |
| Web Header | **Check-in-Chip** (Stimmung/Energie Snapshot heute) — gemeinsame Komponente mit Heute #16 |
| Mobile | Chip **oben auf Heute**, nicht in Tab-Bar |
| Energie live / Stimmung ändern | **Nicht jetzt** — nur Morgen-Snapshot; dynamisches Budget Phase 4 |
| Settings | Account, Theme, Abmelden; **Pro** als Platzhalter („kommt bald“) |
| Legal | `/impressum`, `/datenschutz` — Platzhalter-Inhalt |
| Web Legal-Zugang | **Footer** auf Marketing + optional App-Layout |
| Mobile Legal | Zahnrad auf **Heute** → Einstellungen → Impressum/Datenschutz |
