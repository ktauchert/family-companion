## Ziel

Next.js **`/`** als öffentliche Einstiegsseite — Routing und Minimal-UI. **Marketing-Design** in späterer Phase.

## Entscheidungen (User-Test 2026-09-15)

| Thema | Entscheidung |
| --- | --- |
| `/` | Öffentliche **Landing** (Platzhalter); ausgeloggt Login/Register, eingeloggt „Zur App“ → `/heute` — kein Auto-Redirect |
| Ausgeloggt | Landing mit **Login** / **Register** im Header |
| Eingeloggt | Gleiche Seite, Header **„Zur App“** / **„Zum Dashboard“** → `/heute` |
| Auto-Redirect | **Nein** für eingeloggte Besucher auf `/` (CTA reicht); direkte App-URLs unverändert geschützt |
| Layout | Route-Gruppen `(marketing)` vs `(app)` — Chrome nur in App |
| Inhalt | Platzhalter (Hero + ein Satz Nutzen); Wireframe/Visual **später** |
| Mobile App | Unverändert (Expo); Landing nur Web |
