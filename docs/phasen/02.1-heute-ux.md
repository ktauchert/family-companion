## Ziel

Heute von **Hybrid-Minimal-UI** zum **Dashboard** bringen: scanbare Mini-Cards, einheitliche Icons, Einkauf als Kategorie-Summary, Web/Mobile-Parität. Keine neuen Features (Pro, KI, Energie-Budget).

## Entscheidungen (User-Test + Review 2026-09-15)

| Thema | Entscheidung |
| --- | --- |
| Tagesplan | Flache Liste → **kleine Cards** pro priorisiertem Item |
| Typ-Erkennung | **Icons** (gleich in Tabs/Nav und Cards) |
| Energie-Hinweis | **Gedämpfte Ampel** (sage/clay/warm) + Label/`aria` — nicht nur Farbe |
| Einkauf auf Heute | **Nur Art/Kategorie** + Anzahl offen, keine Produktnamen |
| Dashboard | **Summary-Cards** pro Bereich (Kalender, Listen, Todos) wie `ui.md`-Wireframe — zusätzlich zur Tagesplan-Karte |
| Heute-Aktionen | Erst Darstellung (2.1); **Abhaken auf Heute** optional als T9 / ggf. 2.2 |
| Web vs. Mobile | **Gleiche UI-Elemente und Copy**; Layout darf sich unterscheiden (Raster vs. eine Spalte) |
| Milestones | Ab Phase 2.1 Issues unter GitHub-Milestone; ab Phase 3 weiter so |

## Definition of Done
