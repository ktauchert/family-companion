## Warum eigene Phase?

Phase 1 liefert den Produktpfad mit **E-Mail/Passwort in Expo Go**. Google auf Android braucht einen **eigenen Build** (Play Services, SHA-1, `google-services.json`) — kein Expo Go, kein Web-OAuth, kein `auth.expo.io`. Code und Plugin sind vorbereitet; diese Phase ist **Setup + Gerätetest**, kein neues Feature.

### WP3 — Dev-Build erzeugen und installieren

**Option A — lokal (schneller Iterationszyklus, wenn SDK da):**

```bash
cd apps/mobile
npx expo prebuild --platform android   # nur beim ersten Mal oder nach Plugin-Änderung
npx expo run:android                   # baut und startet auf Gerät/Emulator
```

**Option B — EAS (ohne lokales Android SDK):**

```bash
cd apps/mobile
npm run build:dev:android
# Oder einmaliger Google-Test ohne Metro: npm run build:preview:android
```

Nach dem Build: **Link + QR-Code** auf [expo.dev](https://expo.dev) → Build öffnen → auf dem Gerät installieren (genau wie beim letzten Mal).

**Vor dem ersten EAS-Build** (Secrets, nicht im Repo):

```bash
cd apps/mobile
npx eas login
npx eas env:push --environment development --path .env.local
npx eas secret:create --scope project --name GOOGLE_SERVICES_JSON --type file --value ./google-services.json
```

**SHA-1 bei EAS:** Der Cloud-Build signiert mit dem **EAS-Keystore**, nicht mit dem lokalen Debug-Keystore (`npm run firebase:sha1`). Nach `eas credentials -p android` den **EAS-SHA-1** zusätzlich in Firebase eintragen, `google-services.json` neu laden, ggf. neu bauen. Sonst `DEVELOPER_ERROR` beim Google-Login.

**Dev-Build + Metro:** Nach Installation Dev-Client-App starten, am Rechner `npm run dev:mobile -- --dev-client`, im gleichen WLAN verbinden. **Preview-APK** ist standalone (JS im Paket) — reicht für den reinen Google-E2E-Test.

## Typische Fehler

| Symptom | Erst prüfen |
| --- | --- |
| `DEVELOPER_ERROR` / Sign-In bricht ab | SHA-1 in Firebase, Android OAuth-Client, Paketname `com.familycompanion.app` — **nicht** den Expo-Build-Fingerprint (Projekt-Fingerprint) eintragen, sondern **Keystore-SHA-1** unter Credentials → Android |
| `Missing EXPO_PUBLIC_GOOGLE_WEB_CLIENT_ID` | `.env.local`, App neu bauen (Env sitzt im Build) |
| Google-Button fehlt | Noch **Expo Go** — Dev-Build installieren (`Constants.appOwnership !== 'expo'`) |
| `Google Sign-In lieferte kein idToken` | Falsche Client-ID (Android statt **Web**-Client für `webClientId`) |
| Firestore `permission-denied` nach Login | Rules veröffentlicht (Phase 1), User hat Haushalt / Onboarding |
